# convert

A file converter at [convert.ethantyoung.com](https://convert.ethantyoung.com). It's one page (`site/index.html`) served by nginx. Conversion runs in the browser, so files never leave your computer.

Pushing to `main` puts the change live within about a minute. See [homelab](https://github.com/EthanT-young/homelab) for how deploys work.
